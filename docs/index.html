Caratteristiche Chiave

  • 🔒 Protezione Anti-Lock Playwright Coda FIFO in memoria che gestisce l'accesso seriale al profilo Chrome e pulisce automaticamente i file Singleton* orfani.
  • 📺 Hosting Locale & Byte-Range Streaming Video e immagini salvati in storage/ e serviti su /media/:file con supporto Range: bytes= per scrubbing fluido.
  • 💬 Anteprime Immediate in Chat Generazione istantanea di markdown cliccabile e Data URI Base64 per visualizzare i media direttamente nella chat di Paseo.
  • ⚡ Modalità Sync & Async Chiamate sincrone (fino a 180s) oppure asincrone disaccoppiate passando "wait": false con polling su /v1/tasks/:id.
  • ☁️ Cloudflare R2 On-Demand Passa "upload_r2": true nella richiesta per ottenere anche il link pubblico CDN su bucket video-workflow.
  • 🤖 Compatibilità Drop-In OpenAI Supporta gli endpoint standard /v1/images/generations e /v1/models.

Controllo del Servizio (Systemd)

Il proxy è installato come demone utente permanente su Linux ThinkPad:

# Verificare lo stato del servizio
systemctl --user status gflow-proxy.service

# Leggere i log in tempo reale
journalctl --user -u gflow-proxy.service -f

# Riavviare il proxy
systemctl --user restart gflow-proxy.service

Specifiche degli Endpoint API

GET /health

Restituisce lo stato del servizio, lo stato delle code e gli indirizzi IP disponibili.

curl -s http://localhost:1235/health

POST /v1/video/t2v (Text to Video — Veo 3.1)

ParametroTipoDefaultDescrizione
promptstringobbligatorioDescrizione cinematografica della scena
modelstring"omni-flash"Modello video: omni-flash o veo-2
aspectstring"9:16"Formato: 9:16, 16:9, 1:1
waitbooleantruetrue attende il completamento; false ritorna 202 + task_id
upload_r2booleanfalseSe true, carica anche su Cloudflare R2
 
curl -X POST http://localhost:1235/v1/video/t2v \
  -H "Content-Type: application/json" \
  -d '{
    "prompt": "Cinematic slow motion macro shot of ocean waves at sunrise",
    "model": "omni-flash",
    "aspect": "9:16",
    "wait": true
  }'

POST /v1/images/generations (OpenAI Drop-In)

Compatibile direttamente con gli SDK OpenAI ufficiali:

curl -X POST http://localhost:1235/v1/images/generations \
  -H "Content-Type: application/json" \
  -d '{
    "prompt": "Futuristic neon cyberpunk supercar",
    "size": "1024x1024"
  }'

GET /v1/tasks/:taskId

Permette il polling asincrono dello stato di avanzamento per task lunghi:

curl -s http://localhost:1235/v1/tasks/task_1789223151410_bd7c4787

Esempi di Integrazione Client

Python (`client.py`)

from client import GflowProxyClient

client = GflowProxyClient("http://localhost:1235")

res = client.generate_video_t2v(
    prompt="Cinematic drone shot of desert dunes",
    aspect="9:16",
    wait=True
)

print("Video URL:", res["remote_url"])
print("Markdown Preview:", res["markdown_preview"])

TypeScript / Bun (`client.ts`)

import { GflowProxyClient } from "./client.ts";

const client = new GflowProxyClient("http://localhost:1235");

const result = await client.generateImageT2I({
  prompt: "3D character animation keyframe",
  aspect: "1:1",
  wait: true
});

console.log("Local path:", result.local_path);
console.log("Remote URL:", result.remote_url);
